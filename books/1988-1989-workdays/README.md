# 1988/1989 приг. раб.

«Служебное расписание движения пригородных поездов (1988/1989 г.)»: working
timetable of suburban trains, Riga division of the Baltic Railway (Riga,
«Транспорт», 1988). 103 scans: OCR'd, corrected by hand, rendered back to a
PDF.

| what       | where                                              |
| ---------- | -------------------------------------------------- |
| scan       | `sources/1988-1989_приг_раб.djvu`                  |
| attempts   | `attempts/`, listed in `attempts/index.md`         |
| as printed | `attempts/final-01`                                |
| book fixed | `attempts/normalized-01`                           |
| PDF        | `build/1988-1989-prigorodnye-rabochie.pdf`, built  |
| tool data  | `tools/stop-name-normalizer/`, `tools/stop-times/` |
| OCR format | `spec/ocr-book-format.md` (at the repo root)       |

Page: 101 × 162.9 mm, two to a scan; cover 109.1 mm wide. These and the
validator's mileposts are still set in the scripts (`build_book_pdf.py`,
`validate.py`); see step 5 of `BOOKS-PLAN.md`.
