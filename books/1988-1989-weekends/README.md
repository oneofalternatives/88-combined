# 1988/1989 приг. вых.

«Служебное расписание движения пригородных поездов. В нерабочие дни на лето
1988 года»: working timetable of suburban trains on days off, Riga division of
the Baltic Railway (Riga, «Транспорт», 1988). 83 scans. The weekend companion
of `books/1988-1989-workdays`, with the same layout.

| what       | where                                        |
| ---------- | -------------------------------------------- |
| scan       | `sources/1988-1989_приг_вых.djvu`            |
| attempts   | `attempts/`, listed in `attempts/index.md`   |
| OCR format | `spec/ocr-book-format.md` (at the repo root) |

Scans: 01 is the cover, 02 the title, 82 the imprint, 83 the blank back
cover; 03–81 are spreads, two pages to a scan. Imprint: набор 07.05.88,
печать 20.05.88, бумага 70×90/32, тираж 2500, заказ № 1629.

Формат издания 70×90/32, as in the workdays book, so the page is the same:
101 × 162.9 mm. The spreads are 7446 × 5808 px, about 3× the workdays scan;
the 300 dpi in the DjVu is wrong.

Page size, title and the validator's mileposts are still set for the workdays
book in the scripts (`build_book_pdf.py`, `validate.py`); see step 5 of
`BOOKS-PLAN.md`.
