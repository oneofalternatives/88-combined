# One line per form: <tag> | <form as printed> | <target> | count | scans | shapes | note.
# The target is a spelling printed in final-01, so the pair can be found.

# Notation lines: … is any text, # a number. They cover every name printed
# that way, also those with no twin (О. п. Васкряма).

#   mistake   OCR misread or book typo; fix in the scan files

#   scatter   the book is inconsistent with no pattern; fix or map, by choice
#   form      a consistent form tied to a context (e.g. distance tables spell
#             in full, suburban ones abbreviate); keep, list in the mapping file
#
# count, scans, shapes and note are for review only, not for scoring.
